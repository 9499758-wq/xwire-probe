> 这周出了不少关于自我改进型 agent 的论文。其中相当一部分的提升，其实是 agent 更会做这个 benchmark 了，而不是更会做任务了。所以我们把真正做了检验的论文排在前面。1. Beneath the Surface: What We Overlook When We Talk About Agent Evolution——改进 harness 就能在不更新权重的情况下抬高 benchmark 分数，但这种提升不可靠、代价高，迁移性还差。这篇先读。2. Learning the Task or Learning the Verifier?——把一个自我改进的具身 coding agent 的 benchmark 成功标准给它看，分数就上去了，实际任务完成度并没有。3. Evidence-Governed Adoption of Self-Generated Updates in Autonomous AI Agents——把「agent 写了一个改动」和「agent 把它发出去」分开。每个改动都必须先通过新一轮配对审计和非劣性检验。4. Harness^2: Recursive Agent Harnessing for an Open World——一种没有标准答案、能在新任务上自我改进的 harness：把改动试跑一遍，有用的留下。5. Experience-Handoff Reinforcement Learning for Recursive Self-Improvement——用 RL 训练的 agent 学会了为以后的运行写笔记、整理笔记，而不只是挑更好的动作。6. InfraRSI: Harnessing Recursive Self-Improvement for Training Infrastructure——自我改进最难的地方：分布式训练，一个改错就是 OOM 或者悄无声息的数值漂移。每一项优化都要经过验证。7. Incentivizing Self-Learning in Large Language Models via Reinforcement Learning——给模型一份很长的参考资料，训练它在解题过程中去查、去学，而不是只靠已经会的东西。8. PhysLoop: Harnessing LLMs' Physics Awareness for Self-Improving Video Generation Models——LLM 找出生成视频里的物理错误并指导修正，视频模型就在更干净的数据上得到提升。9. A Cross-Scenario Survey and Analysis of Self-Evolving Multimodal Agents——为什么在推理上管用的自我改进技巧，到了导航或操作任务上经常就失效了。一份不错的领域地图。如果你让 agent 修改自己的配置：谁来定哪些改动留下？测试、人，还是另一个模型？
